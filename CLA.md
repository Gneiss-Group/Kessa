# Contributor License Agreement

Kessa is not yet accepting external code contributions. A formal CLA is in
progress and will be published here before any pull request is merged.

A CLA is required because Kessa ships under a [two-tier license
model](LICENSING.md): the `AGPL-3.0-only` components are also offered under a
separate commercial license, and that is not something the project can do with
contributed code unless the contributor has agreed to it in writing.

If you would like to contribute, please open an issue to discuss first. Do not
submit pull requests until this document is replaced with the finalized CLA
text; they will not be merged, and the work may be wasted.

Bug reports, reproductions, and design feedback need no CLA and are welcome now.
See [`CONTRIBUTING.md`](CONTRIBUTING.md).
